### Selected work

**DeepSeek Harness plugins**

- **[dsh-cpa-switch](https://github.com/cslkkl/dsh-cpa-switch)** · [npm](https://www.npmjs.com/package/dsh-cpa-switch)<br>
  Manage CLIProxyAPI accounts from inside DeepSeek Harness — balance, check-in, tasks, account switching, without opening the web console.

- **[dsh-web-annotator](https://github.com/cslkkl/dsh-web-annotator)** · [npm](https://www.npmjs.com/package/dsh-web-annotator)<br>
  Point at or box a page inside the existing DSH Browser tab, comment in place, ask the current Agent, then send the marked screenshot or DOM locator to the session.

**Frontend visualization**

- **[discography-showcase](https://github.com/cslkkl/discography-showcase)**<br>
  An artist's complete studio catalogue rendered as a record year-ring: 8 artists, 1104 tracks, 14 presentation surfaces, official 30-second previews, full-screen lyric stage. Zero dependencies, no build step, works offline.

**Upstream contributions**

- **[dsh-workbuddy-bridge](https://github.com/dsh-plugin-lab/dsh-workbuddy-bridge)** — 2 merged PRs: per-message credit usage, default tier reporting
- **[awesome-dsh-plugin](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin)** — PR adding dsh-web-annotator merged
- **[Cogniform/imagora](https://github.com/Cogniform/imagora)** — PR for prompt output and portable release merged
