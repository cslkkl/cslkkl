## 精选作品

### 圈出问题，交给 Agent。

`dsh-web-annotator`

<picture>
  <source media="(max-width: 600px)" srcset="assets/dsh-web-annotator-mobile.png">
  <img src="assets/dsh-web-annotator.png" alt="在 DSH 的 Browser 里框选一个标题，旁边就地写着批注，下方列出待发送的批注与发送方式" width="100%">
</picture>

在 DSH 的 Browser 里选中页面的一块，就地写批注，再把标记截图或 DOM 定位发进会话。

[查看项目](https://github.com/cslkkl/dsh-web-annotator) · [npm](https://www.npmjs.com/package/dsh-web-annotator)

### 少开一个控制台。

`dsh-cpa-switch`

<picture>
  <source media="(max-width: 600px)" srcset="assets/dsh-cpa-switch-demo-mobile.png">
  <img src="assets/dsh-cpa-switch-demo.png" alt="CPA 切换器面板：四个渠道页签、剩余 / 已用 / 额度池汇总，以及标着 Demo Account A、B、C 的三张账号卡。示意数据，不是真实账号。" width="100%">
</picture>

看余额、签到、切换账号都在当前工作界面完成；CPA 跟着 DSH 一起启停。

*配图使用虚构演示账号与演示额度。*

[查看项目](https://github.com/cslkkl/dsh-cpa-switch) · [npm](https://www.npmjs.com/package/dsh-cpa-switch)
